# CNKI AI 个性化需求原型

高保真页面原型，对应五项机构个性化需求。本地预览：

```bash
# 任选一种静态服务方式
python3 -m http.server 8080 --directory prototypes
# 然后打开 http://localhost:8080
```

或直接打开 `prototypes/index.html`。
